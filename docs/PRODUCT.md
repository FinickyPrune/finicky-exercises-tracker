# Продукт

## Идея

Трекер ежедневных рутин. Утром открываешь приложение и сразу видишь, что сделать сегодня: не нужно вспоминать, поэтому не делаешь меньше, чем хотел. Проходишь по списку, отмечаешь сделанное, получаешь приятный отклик — анимацию и хаптик.

Первая рутина — утренняя зарядка. Но зарядка — лишь один из блоков: рядом могут стоять дневник, урок Duolingo или что угодно, что пользователь соберёт сам.

Для себя, без подписок и аккаунтов. Данные живут локально на телефоне.

## Глоссарий

| Термин | В коде | Что это |
|---|---|---|
| Часть дня | `DayPart` | Верхний уровень: «Утро», «Вечер». Имеет время начала — приложение само открывает текущую. |
| Рутина | `Routine` | Блок внутри части дня: «Зарядка», «Дневник», «Duolingo». Имеет расписание по дням недели. Состоит из шагов. |
| Шаг | `Step` | Кирпичик конструктора. Виды: упражнение, ссылка, отметка. Новые виды добавляются без изменения остальной модели. |
| Упражнение | `Exercise` | Запись в библиотеке: название, описание, фото-подсказка. Шаги ссылаются на библиотеку, поэтому прогресс по упражнению виден независимо от рутины. |
| Выполнение | `RoutineRun` | Факт прохождения рутины в конкретный день: снимок плана и что сделано на самом деле. |
| Серия | — | Дни подряд с выполненным планом. |

## Пользовательские сценарии

1. **Утро.** Открываю приложение — вижу «Утро» с рутинами на сегодня и общий прогресс.
   - Duolingo: тап по ячейке открывает приложение Duolingo; после возвращения ставлю галочку прямо в списке.
   - Зарядка: открывается экран-чеклист. «Сделано по плану» — один тап; если повторов было меньше — поправляю вторичной кнопкой. Для планки жму play — появляется таймер, по окончании хаптик.
   - Последняя рутина закрыта — финальная анимация.
2. **Настройка.** Собираю рутину из шагов, выбираю дни недели. Добавляю упражнения в библиотеку с фото-подсказкой из галереи.
3. **Прогресс.** Смотрю серию и графики по упражнениям.
4. **Зал** (позже). Самостоятельная тренировка с весами и историей подходов.

## Принципы

- Отметить «сделано по плану» — один тап. Редактирование факта — вторичное действие.
- Каждое выполненное действие сопровождается хаптиком и анимацией.
- Пропуск дня не должен обнулять мотивацию: правила серии мягкие.
- Никаких подписок, аккаунтов и сети.

## Объём и порядок

Каждая подзадача — одна сессия Claude и один PR. Номера используются в названиях веток и issues.

### Milestone 1 — «Утро» (MVP)

Минимум, с которым приложением можно пользоваться каждое утро.

**F0. Дизайн-система** — подробности в [DESIGN.md](DESIGN.md)
- 0.1 Визуальное направление: 2–3 варианта экранов «Сегодня» и «Зарядка» на SwiftUI с демо-данными, скриншоты из симулятора, выбор одного.
- 0.2 Токены (цвета для светлой и тёмной темы, отступы, радиусы, типографика) и отладочная галерея дизайн-системы.
- 0.3 Базовые компоненты: `DayPartHeader`, `RoutineCard`, `EmptySlot`, `PlanBadge`, `CapsuleButton`.
- 0.4 Отклик: каталог хаптиков и анимаций выполнения.

**F1. Модель данных и хранение**
- 1.1 Шаблоны: `DayPart`, `Routine`, `Step` + `StepConfig` (упражнение / ссылка / отметка), `Exercise`. SwiftData, версионированная схема v1.
- 1.2 Выполнения: `RoutineRun`, `StepResult` со снимком плана и фактом.
- 1.3 Слой хранилища: контейнер в памяти для тестов и превью, демо-данные («моё утро»).
- 1.4 Расписание: «что сегодня» по дню недели и текущая часть дня по времени. Чистая логика + тесты.

**F2. Экран «Сегодня»**
- 2.1 Текущая часть дня и рутины на сегодня с прогрессом.
- 2.2 Простые рутины (один шаг-ссылка или отметка) выполняются прямо в списке: ссылка открывает приложение, галочка закрывает рутину.
- 2.3 Переход на экран рутины для составных рутин.
- 2.4 Переключение между частями дня.

**F3. Выполнение рутины**
- 3.1 Чеклист шагов. Ячейка упражнения: название, план (3 × 15 или 3 × 30 с), миниатюра фото.
- 3.2 «По плану» одним тапом — отмечает всё упражнение сразу; повторы по подходам правятся вторичной кнопкой.
- 3.3 Таймер для упражнений на время: play в ячейке → таймер в шторке внутри приложения (sheet), хаптик и звук в конце; срабатывает и при заблокированном экране (локальное уведомление).
- 3.4 Завершение рутины: финальная анимация, хаптик, сохранение выполнения.
- 3.5 Просмотр фото-подсказки на весь экран.

**F4. Конструктор**
- 4.1 Части дня: создать, переименовать, задать время начала, упорядочить.
- 4.2 Рутина: название, иконка, цвет, дни недели; добавить, упорядочить, удалить шаги.
- 4.3 Редакторы шагов: упражнение (из библиотеки; подходы; повторы или время; отдых), ссылка (пресеты Duolingo и Journal + свой URL), отметка.
- 4.4 Библиотека упражнений: название, описание, фото из галереи.

Порядок: F0 и F1 параллельно → F3 → F2 → F4. Конструктор идёт после выполнения: пока его нет, рутины берутся из демо-данных, и приложением уже можно пользоваться.

### Milestone 2 — «Прогресс»

- **F5. Серия**: дни подряд с выполненным планом. Правила не решены — см. открытые вопросы.
- **F6. Графики**: динамика по упражнению, календарь выполненных дней.
- **F7. Виджет на экране блокировки**: прогресс утра (и серия, когда появится); интерактивная галочка для простых рутин.
- **F8. Apple Health**: запись тренировки после зарядки — тип, длительность, калории.
- **F9. Таймер в Live Activity** (Dynamic Island и экран блокировки).
- **F10. Фото с камеры.**

### Milestone 3 — «Зал»

- **F11. Силовое упражнение**: вес × повторы, история подходов, подсказка прошлого результата, таймер отдыха.

### Идеи без срока

Утреннее напоминание; шаги «текст», «счётчик», «фото»; резервная копия или синхронизация через iCloud.

## Открытые вопросы

1. **Правила серии** (F5). Прерывание серии демотивирует, поэтому правила нужны мягкие. Кандидат: считаются только запланированные дни; день засчитан, если выполнена хотя бы одна рутина; один пропуск в неделю серию не прерывает.
2. **Калории для Apple Health** (F8). Без Apple Watch их можно только оценить (MET × вес × длительность) или не писать вовсе.
