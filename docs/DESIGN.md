# Дизайн

## Направление

Тёпло и мягко: оранжевый акцент на тёплом светлом фоне, большие сглаженные скругления, крупные цифры. Основа — стандартный iOS 26 (Liquid Glass, Dynamic Type, тёмная тема), поверх — свой слой токенов и компонентов.

Референсы — скриншоты чужих приложений, поэтому в git их нет: папка `docs/design/references/` в `.gitignore` и лежит только в основной копии репозитория (в worktree Claude Code она подключается симлинком, см. `.claude/settings.json`). Если папки нет — опирайся на описание ниже.

- **Gentler** (`gentler-activities.webp`) — палитра и характер. Тёплый оранжевый; светло-серые карточки с большими скруглениями; выделенная карточка залита оранжевым с белым текстом; крупное значение и мелкая единица («59m»); подписи капсом с разрядкой; сегменты и кнопки-капсулы.
- **Tiimo** (`tiimo-day.webp`, `tiimo-quick-add.webp`, `tiimo-add-task.webp`) — организация. День разбит на части с цветными капсулами-заголовками (иконка, название, счётчик, сворачивание); пустая часть дня — пунктирный слот с «+»; быстрое добавление в шторке с чипами; форма из сгруппированных карточек со значениями-капсулами справа.

### Выбрано в 0.1: вариант A «Gentler»

Сравнивали три варианта на одних демо-данных; скриншоты всех трёх в светлой и тёмной теме — в [`docs/design/0.1/`](design/0.1/) (`a-*` — выбранный, `b-*` — Tiimo, `c-*` — гибрид).

- **Заголовки — SF Pro**, не New York.
- **«Сегодня»:** часть дня — жирный заголовок секции с подписью капсом («1 из 4 · с 7:00»), без цветной капсулы. Рутины — плитки в две колонки; текущая рутина залита акцентом целиком, выполненные приглушены и отмечены галочкой. Пустая часть дня — пунктирный слот из Tiimo.
- **«Зарядка»:** крупный заголовок, счётчик «2 из 6» и полоса прогресса. Упражнения — строки-карточки; следующее невыполненное залито акцентом. Справа круглая кнопка «по плану» (44 pt), у упражнений на время перед ней — play. Внизу — тёмная кнопка-капсула «Завершить».
- **Плотность просторная:** между секциями 32, между карточками 12, внутренний отступ карточки 20.
- Известный минус: плитки занимают много места, вечер уходит за первый экран. Принимаем — утром важна текущая часть дня, остальные доступны прокруткой и переключателем (2.4).

## Принципы

1. **Тепло.** Тёплые нейтральные фоны, без чистого серого и синего. Холодные цвета — только редкими акцентами в палитре рутин.
2. **Мягко.** Сглаженные (continuous) скругления, капсулы и круги. Никаких острых углов и тонких рамок — кроме пунктира пустых слотов.
3. **Один акцент.** Оранжевый означает «действие и выполнение». Всё остальное нейтральное.
4. **Цифры — главные.** План и факт («3 × 15», «0:30») крупно, единицы мельче.
5. **Каждое выполнение ощущается.** Хаптик и анимация из каталога отклика — без исключений.
6. **Системное — системным.** Навигация, таб-бар, шторки, кнопки тулбара — стандартные компоненты iOS 26 с Liquid Glass. Не перерисовываем.

## Токены

Цвета, формы и основная типографика проверены в 0.1 на экранах «Сегодня» и «Зарядка» в обеих темах. С 0.2 все токены живут в модуле `DesignSystem` (`DesignSystem/Tokens/`), а галерея показывает их в светлой и тёмной теме, с повышенным контрастом и на крупном шрифте. Ещё не проверялись на реальных экранах: таймер (`TimerSheet`), сворачивание частей дня, хаптики (только на телефоне).

Имена в коде: цвета — `Palette.accent` и т. д. (`ColorToken` — это `ShapeStyle`, сам выбирает значение по теме и контрасту: `.foregroundStyle(Palette.accent)`); части дня — `DayPartTint`; палитра рутин — `RoutineTint`; отступы — `Spacing`, радиусы — `Radius` и формы `.card`, `.row`, `.small`; размеры — `Size`; прозрачность — `Opacity`; шрифты — `Font.screenTitle`, `.sectionTitle`, `.itemTitle`, `.itemStatus`, `.planNumber()`, `.planUnit`, `.timer` и модификатор `.capsLabel()`; контраст — `Contrast.ratio`.

Акцент практически совпадает с оранжевым Gentler (`#FC7E3D`). Нейтральные цвета, наоборот, теплее, чем у Gentler (там белый фон и холодно-серые карточки `#F1F1F3`).

### Формы и отступы

- Радиусы: карточка — 28, строка — 20, мелкие элементы — 12, кнопки и чипы — капсула. Всегда `.continuous`.
- Отступы: шкала 4 · 8 · 12 · 16 · 20 · 24 · 32. Поля экрана — 20.
- Размеры (масштабируются с Dynamic Type через `@ScaledMetric`): круглая кнопка — 44, иконка рутины в круге — 40, миниатюра упражнения — 56 (радиус 12), минимальная высота плитки рутины — 132, полоса прогресса — 8.
- Выполненное приглушается прозрачностью 0,6 (`Opacity.completed`). В строке шага кнопка-галочка остаётся яркой (её можно снять); плитка рутины приглушается целиком, вместе с галочкой-статусом.
- Фон под цветной иконкой — её цвет с прозрачностью 0,16 (`Opacity.iconFill`); полупрозрачные заливки на акценте — белый с прозрачностью 0,22 (`Opacity.onAccentFill`).

## Отклик: хаптики и анимации

| Событие | Хаптик | Анимация |
|---|---|---|
| Шаг выполнен по плану | `.success` | галочка прорисовывается, строка приглушается |
| Факт изменён | `.selection` | цифры перетекают (`.numericText`) |
| Рутина завершена | `.success`, усиленный | карточка заливается акцентом, короткая вспышка |
| Часть дня завершена | `.success` | праздничная анимация на весь экран, до 1,5 с |
| Таймер: последние 3 секунды | `.impact(weight: .light)` каждую секунду | пульс кольца |
| Таймер завершён | `.impact(weight: .heavy)` + звук | кольцо замыкается |
| Отмена выполнения | `.impact(flexibility: .soft)` | обратная анимация |

- Анимации — только пружины: `.snappy` для взаимодействий, `.bouncy` для празднований.
- При включённом «Уменьшении движения» празднования заменяются простым появлением.
- Хаптики проверяются на iPhone: симулятор не вибрирует.

## Правила для кода

- Дизайн-система — отдельный модуль `DesignSystem` (framework-таргет, см. ARCHITECTURE.md): `Tokens` (цвета, отступы, радиусы, размеры, типографика), `Components`, `Feedback` (хаптики и анимации). Фичи делают `import DesignSystem` и видят только его `public` API.
- В `Features/` запрещены литералы цветов, шрифтов, отступов и радиусов, а также прямые вызовы хаптиков. Только токены, компоненты и события отклика.
- Новый компонент — сразу в дизайн-систему, с `#Preview` и в галерею.
- Каждый компонент проверяется в светлой и тёмной теме и на крупном шрифте (Dynamic Type XXL). Размеры — через `@ScaledMetric`, без фиксированных `frame`; на размерах доступности сетка рутин переходит в одну колонку.
- Доступность в каждом компоненте: декоративные SF Symbols — `.accessibilityHidden(true)`; кнопка-галочка — переключатель (`.isToggle`), а не кнопка без действия; строка и плитка — один элемент для VoiceOver; заголовки экранов и секций — `.isHeader`; прогресс озвучивается значением.
- Внутри `NavigationLink` нет других кнопок: внутренняя кнопка перехватывает нажатие. Призыв к действию — сама ссылка или программная навигация.
- Прогресс ограничен `0...1`, деление на ноль при пустом списке исключено.
- **Галерея**: отладочный экран «Design System» (только Debug-сборки) со всеми токенами и компонентами во всех состояниях. Живёт в приложении за `#if DEBUG` (`ExercisesTracker/Debug/Gallery/`), отдельного app-таргета у неё нет; открывается кнопкой в тулбаре корневого экрана. По её скриншотам идёт ревью: аргументы запуска `-showGallery YES` открывают её сразу, `-gallerySection <id>` прокручивают к секции (colors, contrast, dayParts, routines, typography, spacing, shapes).
